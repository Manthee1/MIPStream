# Adder
The Adder module performs binary addition of two unsigned integers.

## Functionality
- **A + B**: Sums two inputs of configurable bit width.
- **Carry In**: Includes an optional carry-in bit for chaining adders.
- **Carry Out**: Provides a carry-out bit indicating overflow or for chaining.

## Usage
Used in the ALU for arithmetic operations or as a dedicated PC incrementer.
