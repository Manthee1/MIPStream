# Multiplexer
The Multiplexer (MUX) selects one of multiple data inputs and forwards it to a single output line.

## Functionality
- **Data Selection**: Uses a selection (SEL) signal to determine which input to pass.
- **Configurable Inputs**: Supports a variable number of input ports.

## Truth Table Example (2-to-1)
| SEL | OUT |
|-----|-----|
| 0   | IN0 |
| 1   | IN1 |
