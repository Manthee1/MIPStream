# Shifter
The Shifter module performs bitwise shifting operations.

## Operations
- **Logical Left (LSL)**: Shifts bits to the left, filling with zeros.
- **Logical Right (LSR)**: Shifts bits to the right, filling with zeros.
- **Arithmetic Right (ASR)**: Shifts bits to the right, preserving the sign bit.

## Usage
Essential for instruction decoding and implementing shift-type instructions.
